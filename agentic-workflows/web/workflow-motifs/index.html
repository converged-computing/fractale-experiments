Scientific Topology

1. Hybrid Tokenization

Each workflow step is treated as a "document." We extract software packages (conda), but also semantic tokens from the entire rule block, and we filter out common Snakemake or command terms (e.g., sort or script). This captures scientific intent beyond tool name.

2. Latent Semantic Discovery

We use TF-IDF to identify high-signal tokens and Truncated SVD to compress thousands of terms into 50 core "Scientific Concepts." This allows us to see different rules doing similar work that belong together (e.g., If bwa and bowtie2 are both associated with samtools, we can conclude that bwa and bowtie2 are conceptually similar).

3. Archetype Clustering

Using K-Means, we group steps into Archetypes (Phenotypes). A label like "bwa | mem | fastq" represents the statistical center of a cluster of similar scientific actions discovered across 5,000+ workflows.

4. Motif Reconstruction & Scale

We leverage two different scales of data.

Global Archetypes (5,000+ Workflows): We used the full Snakemake catalog to define the phenotypes. This ensures our categories are representative of the entire scientific community.

Structural Motifs (128 Ground-Truth DAGs): We parsed 128 DAG files to observe how these archetypes connect. This sub-sample provided over 6,700 total transitions and 316 unique motifs, allowing us to see a sample of common patterns in scientific pipelines.
