OSU Micro-Benchmarks: osu_allreduce (MPI_Allreduce Latency Test, blocking collective)
Same osu_allreduce binary/source; accelerator support is compile-time optional (configure --enable-cuda/--enable-rocm/--enable-sycl) and runtime-optional via options.accel/D-D args. When enabled, uses GPU-aware MPI to pass device buffers directly into MPI_Allreduce.
mpirun_rsh -np &lt;N&gt; -hostfile hostfile ./osu_allreduce   (or mpirun -np &lt;N&gt; ./osu_allreduce)
