miniFE CUDA (MPI+GPU) CG solver
GPU-offloaded CG, one device per rank. Bandwidth-bound sparse matvec on device; latency-sensitive small MPI halo + scalar allreduce. GPUDIRECT build wants co-located GPUs with fast interconnect. No parallel I/O.
