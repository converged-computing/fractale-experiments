LAMMPS ReaxFF (pair reaxff + fix qeq/reaxff), MPI build
Communication is moderate: the QEq CG solver runs many (up to 200) iterations, each doing a neighbor halo exchange plus a couple of small global Allreduces. Force compute (bond-order many-body terms) is the dominant cost, so compute-bound with moderate arithmetic intensity.
