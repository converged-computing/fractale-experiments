AMG communication pattern
No accelerator, no parallel I/O, no checkpoint. NUMA-sensitive because OpenMP threads within MPI tasks and memory-access bound. Runs from single node up to >1M ranks; neighbor/reduction comm favors packed/neighbor placement with co-location for the frequent halo+allreduce traffic.
