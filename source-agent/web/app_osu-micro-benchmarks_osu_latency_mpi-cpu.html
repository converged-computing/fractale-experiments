OSU MPI point-to-point latency (ping-pong), CPU buffers
Requires EXACTLY 2 processes (aborts otherwise). Placement is a diagnostic choice: as a benchmark it is run either intra-node (same node = measures shared-mem/loopback latency) or inter-node (spread = measures fabric latency); neither is required by the code.
