LAMMPS pair_style reaxff/omp (MPI + OpenMP hybrid CPU)
reaxff/omp adds OpenMP threading over the base MPI decomposition (hybrid MPI+X). Same neighbor exchange + QEq CG (Allreduce) comm shape as CPU reaxff. Thread affinity/NUMA binding matters (OMP_PROC_BIND). Threads/task not fixed by any real reaxff invocation in repo; example value shown.
OMP_NUM_THREADS=4 mpirun -np 8 lmp -sf omp -pk omp 4 -in in.reaxff
