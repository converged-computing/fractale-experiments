us.anthropic.claude-opus-4-8 — what the model said

OSU MPI latency with device (GPU) buffers
Same 2-rank ping-pong but with GPU-resident buffers when built with --enable-cuda (or --enable-rocm=rocm/--enable-sycl). Runtime args D/H/M select device/host/managed buffers per side. Device pointers are handed to MPI_Send/Recv, so it exercises GPU-aware MPI (not NCCL). Each rank binds to one local GPU (get_local_rank helper). ROCm build would set accelerator.kind=rocm, SYCL build=sycl.
mpirun -np 2 --hostfile hosts osu_latency D D
