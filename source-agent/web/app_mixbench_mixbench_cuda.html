mixbench-cuda GPU microbenchmark (launch/topology)
Single-process, single-GPU CUDA benchmark: selects one device via cudaSetDevice, launches a series of CUDA kernels (<<<dimGrid,dimBlock>>>) sweeping compute/memory operational-intensity, measures kernel time with CUDA events, copies result back once. No MPI, no multi-GPU, no inter-process communication.
./mixbench-cuda [GPU_ID]
