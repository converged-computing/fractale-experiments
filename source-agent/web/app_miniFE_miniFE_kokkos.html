miniFE MPI+Kokkos portable-parallel implementation (kokkos/ variant, default OpenMP backend)
Kokkos build (kokkos/src/Makefile) sets KOKKOS_DEVICES=OpenMP by default; Kokkos itself is portable and could target Cuda if reconfigured (KOKKOS_DEVICES=Cuda), but as checked-in build it is an MPI+OpenMP hybrid akin to the openmp variant, using the same MPI Isend/Irecv neighbor-exchange pattern (kokkos/src/exchange_externals.hpp) and MPI_Allreduce for dot-products (kokkos/src/Vector_functions.hpp:180-182).
