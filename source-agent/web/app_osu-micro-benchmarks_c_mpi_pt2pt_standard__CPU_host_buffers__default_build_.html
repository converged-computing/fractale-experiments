OSU MPI point-to-point latency benchmark (2-rank ping-pong)
osu_latency is built from c/mpi/pt2pt/standard/osu_latency.c via autotools (configure.ac) into a standalone MPI executable. It is a strict 2-rank ping-pong: rank 0 MPI_Send then MPI_Recv, rank 1 MPI_Recv then MPI_Send, repeated over increasing message sizes, timed with MPI_Wtime around MPI_Barrier-synchronized loops. No threading in default build.
mpirun -np 2 [--hostfile hosts] ./osu_latency [-d TYPE] [H|D H|D]
