us.anthropic.claude-opus-4-8 — what the model said

HPL 2.3 Linpack benchmark (reference MPI build)
Topology is judgment. HPL is a benchmark run at any scale from single node to full cluster (either). Placement: pack for locality/bandwidth since panel broadcasts and U-rolls are frequent along grid rows/columns; TUNING notes performance depends on comm/compute ratio. Co-location preferred because comm-heavy nearest-neighbor exchange on the 2D grid benefits from ranks landing close; not required (no shared memory).
mpirun -np 4 xhpl
