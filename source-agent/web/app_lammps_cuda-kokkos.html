LAMMPS ReaxFF Kokkos CUDA (pair reaxff/kk on NVIDIA GPUs)
Same {neighbor,reduction} sparse-solver pattern as CPU, executed on GPU. Halo exchange + per-CG-iter reductions cross GPUs via GPU-aware MPI; docs strongly recommend it, so wants a fast GPU interconnect between co-located devices.
mpirun -np 2 lmp -k on g 2 -sf kk -pk kokkos gpu/aware on -in in.reaxff
