AMG2023 CPU build (MPI+OpenMP, hypre-based algebraic multigrid solver)
AMG2023 is a SPMD benchmark solver (hypre-based algebraic multigrid) built as a single executable 'amg'. README explicitly states it is SPMD using MPI + OpenMP threading within MPI tasks, with data decomposition into a logical PxQxR processor grid (-P px py pz command line option, amg.c:334). This variant covers the default CMake config with AMG_WITH_MPI=TRUE (default) and optionally AMG_WITH_OMP=TRUE (CMakeLists.txt:21,25). No GPU, no checkpoint/restart, no parallel I/O library found in source.
mpirun -np <P*Q*R> ./amg -P <px> <py> <pz> -n <nx> <ny> <nz>
