OSU MPI Bandwidth Test (osu_bw), standard build
osu_bw is a fixed 2-rank MPI point-to-point streaming bandwidth microbenchmark: rank 0 posts a window of MPI_Isend, waits, then blocks on a small ack MPI_Recv; rank 1 posts matching MPI_Irecv window. Message sizes sweep min->max; window_size (default 64) governs pipelining depth. Purely CPU/host-memory in this variant (no accel flag).
mpirun -np 2 ./osu_bw  (or mpirun_rsh -np 2 -hostfile hostfile osu_bw)
