OSU MPI point-to-point latency benchmark, GPU (CUDA/ROCm) buffer variant
Same 2-rank ping-pong core loop as CPU variant, but built with --enable-cuda/--enable-rocm (configure.ac) so send/recv buffers can be allocated on GPU device memory (D D flags) and exercised through CUDA-aware MPI. Communication pattern/intensity/latency-sensitivity assertions are identical to the CPU variant and are recorded there; this record only adds accelerator-specific facts.
