OSU MPI Bandwidth Test (osu_bw), CUDA/ROCm accelerator build
When configured --enable-cuda (or --enable-rocm/--enable-openacc/--enable-sycl), osu_bw allocates its send/recv buffers on GPU device memory (D) or host-pinned memory (H) per CLI args ('D'/'H'/'M'), using CUDA driver context (init_accel) and, for managed memory, CUDA kernels to touch buffers. Still a fixed 2-rank MPI job; one GPU expected per rank (rank0 device buffer <-> rank1 host or device buffer), relying on a GPU-aware/CUDA-aware MPI implementation (e.g. MVAPICH2-GDR) for the actual device-to-device transfer path -- no NCCL usage in this pt2pt code.
mpirun_rsh -np 2 -hostfile hostfile MV2_USE_CUDA=1 osu_bw D H
