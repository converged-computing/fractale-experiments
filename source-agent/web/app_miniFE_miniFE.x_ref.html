miniFE reference (MPI-only) CG solver
CG has per-iteration nearest-neighbor halo exchange (small messages, latency-sensitive) + one Allreduce per dot. No parallel I/O or checkpoint; writes a YAML report at end. Neighbor/pack placement preferred.
