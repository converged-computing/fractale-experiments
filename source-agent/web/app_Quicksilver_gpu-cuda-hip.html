Quicksilver MC transport, GPU build (CUDA/HIP, unified memory)
GPU build needs a device co-located with each rank (co_location required at rank level). No explicit GPU launch geometry stated in repo examples (CORAL2/CTS2 decks are CPU srun runs); gpus_per_task=1 is inferred from single gpu_id per rank, not a literal invocation.
