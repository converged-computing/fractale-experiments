us.anthropic.claude-sonnet-5 — what the model said

BoomerAMG algebraic multigrid solver, CPU MPI(+OpenMP) build (default, no GPU)
HYPRE builds a static/shared library (libHYPRE); BoomerAMG (HYPRE_parcsr_ls) is invoked from user apps or hypre's own drivers (src/test/*ij*.c, src/examples/ex5/ex11/etc). Core kernel is ParCSR matvec used in AMG V-cycle relaxation, using nearest-neighbor Isend/Irecv exchange via CommPkg (halo exchange over the parallel matrix graph), plus MPI_Allreduce for norms/dot products in Krylov wrappers (PCG/GMRES) and in setup (grid partitioning, global sizes). OpenMP threading available via HYPRE_ENABLE_OPENMP for box loops / SpMV kernels on CPU.
mpirun -np <N> ij  (or any driver linking libHYPRE, e.g. src/examples/ex5, src/test/new_ij.c)
