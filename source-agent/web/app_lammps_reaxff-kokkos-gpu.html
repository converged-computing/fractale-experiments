LAMMPS pair_style reaxff/kk (Kokkos, GPU-capable)
Kokkos-accelerated pair_style reaxff/kk (device or host backend, selectable via reaxff/kk/device or reaxff/kk/host). One MPI rank typically drives one GPU (LAMMPS Kokkos convention); QEq/ACKS2 fixes have Kokkos ports (fix_qeq_reaxff_kokkos, fix_acks2_reaxff_kokkos) that still rely on MPI halo exchange (comm->forward/reverse_comm) and MPI_Allreduce for CG dot products, now operating on device-resident data, so cross-rank communication of GPU data (or GPU-aware MPI) matters for multi-GPU/multi-node runs. Confidence on exact accelerator backend (CUDA vs ROCM/HIP) is lower since Kokkos is backend-agnostic; contributor list includes both NVIDIA and AMD authors.
