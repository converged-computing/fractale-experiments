LAMMPS pair_style reaxff / reaxff-omp (CPU, MPI+OpenMP)
CPU variant (pair_style reaxff and reaxff/omp). Domain-decomposed MD: LAMMPS core exchanges ghost atoms/forces via comm->forward_comm/reverse_comm (halo/neighbor pattern) each timestep and each QEq charge-equilibration CG iteration. QEq CG solver (fix qeq/reaxff, used almost universally with pair_style reaxff) performs MPI_Allreduce (parallel_dot/parallel_norm) every iteration -- small, frequent, global reductions -> latency sensitive. OpenMP variant (reaxff/omp) adds intra-node thread parallelism on top of MPI (hybrid), so rank/thread placement (NUMA) matters.
mpirun -np N lmp -in in.reaxff.rdx (optionally -sf omp -pk omp T)
