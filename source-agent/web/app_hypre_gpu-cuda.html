us.anthropic.claude-sonnet-5 — what the model said

BoomerAMG algebraic multigrid solver, GPU (CUDA/HIP) build, one GPU per MPI rank
Same MPI/ParCSR communication pattern as CPU build (neighbor exchange for matvec + Allreduce for norms), but with HYPRE_ENABLE_CUDA/HIP/SYCL: matrices/vectors default to HYPRE_MEMORY_DEVICE, AMG setup/solve execute on device (HYPRE_EXEC_DEVICE), SpGEMM/RNG can use vendor libs or hypre's own. Optional HYPRE_ENABLE_GPU_AWARE_MPI lets neighbor-exchange buffers move directly GPU-to-GPU without host staging. Doc explicitly shows per-rank cudaSetDevice binding pattern -- implies rank<->GPU pinning and preferring co-located GPUs for the MPI neighbor communication.
mpirun -np <N> ij   (each rank calls cudaSetDevice(device_id) before HYPRE_Initialize(); one GPU bound per rank)
